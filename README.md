# Hamburg Mensa Shortcuts (für Apple Kurzbefehle)

Apple Kurzbefehle für die Mensen des Studierendenwerks Hamburg.
Mit einem Tap den aktuellen Speiseplan direkt auf iPhone, iPad oder Mac anzeigen lassen, ohne extra App und ohne sich durch die Website zu klicken.
Have fun!

## Hinweis

Dies ist ein privates Projekt und steht in keiner Verbindung zum Studierendenwerk Hamburg (STWHH).

Die Shortcuts funktionieren, indem Inhalte von der offiziellen Website ausgelesen werden.
Falls das STWHH Änderungen an der Website vornimmt, können die Shortcuts jederzeit nicht mehr funktionieren. Ich übernehme keine Garantie für Funktion, Vollständigkeit oder Richtigkeit der Daten.
